# ChRIS-overview

Before doing anything else in this repository, read [`docs/status.adoc`](docs/status.adoc). It is the persistent memory for this project: how the author works, how to build the deck, what has been decided, and what is still open. Then read [`docs/notes.adoc`](docs/notes.adoc) for the reasoning behind each concept in the talk.

Keep project memory in `docs/status.adoc`, not in a session-local memory directory. Session memory stays on one machine; this file travels with the clone. When a decision is made or an open point is closed, update the file in the same change, and delete what has gone stale.

This repository is public and deploys to GitHub Pages on every push to `master`. The HARBOR Task Description Document is private. Don't quote it.
